# SAP ABAP Sales Order Report

Junior-level SAP ABAP ECC portfolio project.

## Purpose

This report displays sales order information using standard SAP SD tables.

## Tables Used

- VBAK - Sales Document Header
- VBAP - Sales Document Item
- KNA1 - Customer Master
- MAKT - Material Descriptions

## Planned Features

- Selection screen
- Open SQL JOINs
- Sales order header and item data
- Customer information
- Material descriptions
- ALV output
- Input validation
- Basic performance considerations

## ABAP Concepts Demonstrated

- ABAP Reports
- Open SQL
- JOINs
- Internal Tables
- Selection Screens
- CL_SALV_TABLE
- Basic Object-Oriented ABAP

## Environment

Developed and tested in an SAP ECC training environment.
